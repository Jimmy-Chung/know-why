# Know Know

以会话卡片、知识分支和自然语言知识助手组织个人探索的 Web 应用。

1.0 定位：个人本机使用，通过浏览器访问本地服务，**不包含登录模块**。下一版本 1.1 加入多用户登录与用户数据隔离。

## 当前状态

已完成需求讨论及可点击的 UI 原型，并归档为 1.0 需求与交互基线。工程当前包含文档和原型；真实模型调用、联网搜索、持久存储及知识检索尚未开发。版本号不代表已发布正式应用，测试用例尚未执行。

现有 UI 原型为示例内容，不能替代正式应用，也不能用其判断真实 API 是否接通。
