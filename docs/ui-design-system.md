# UI 样式规范与本轮验证

2026-09-08。本轮只调整客户端布局、视觉样式和展示组件；服务端、RAG、上下文、消息持久化和 Provider 绑定规则未改动。测试样例使用独立临时 SQLite 与本机模拟 Provider。

## 样式结构

`src/client/styles.css` 只声明导入顺序，不再直接堆积组件规则。

| 文件 | 职责 |
| --- | --- |
| `styles/tokens.css` | 明暗主题语义色、字号、间距、圆角、阴影、控件高度、阅读宽度、层级与动画变量 |
| `styles/base.css` | 文档默认值、重置、键盘焦点、选区和滚动条 |
| `styles/controls.css` | 共享按钮及 Arco 确认框/提示框的主题适配 |
| `styles/prose.css` | 主卡片、助手、卡片预览共享的 Markdown 阅读排版 |
| `styles/layout.css`、`sidebar.css` | 工作区框架、会话栏、导航与模型信息 |
| `styles/cards.css`、`tree.css` | 卡片堆叠、输入区和分支树 |
| `styles/assistant.css`、`overlays.css` | 助手面板、设置、来源浮窗与卡片预览 |
| `styles/responsive.css` | 集中管理桌面、紧凑窗口和窄屏的布局策略 |

### 开发约定

- 新的颜色先定义语义 token。不要在组件里判断深色模式，不要硬编码白字搭配浅色强调色。
- 功能按钮优先使用 `components/ui/Button.tsx`；图标按钮使用 `IconButton`，必须提供 `label`。图标统一来自 `ui/Icon.tsx`。
- 按钮只使用 primary / secondary / ghost 三种基础表达。组件样式负责摆放位置，按钮尺寸、颜色与状态由共享层负责。
- 基础规则不能用包含复杂选择器的 `:is()` 集合覆盖变体，避免集合最高优先级使 primary/ghost 失效；共享按钮的选择器独立列出。
- 正文使用 `.msg-answer`，避免在助手或预览中另复制一套 Markdown 样式。
- 间距、字号、圆角优先复用 token；图形坐标和由拖拽产生的动态位置可局部计算。不要把数据状态或请求逻辑放进样式层。
- 动态内联样式限于必要的宽度、坐标和旋转值。助手宽度通过 `--assistant-width` 传入，响应式文件决定它如何参与布局。
- 不在 `styles.css` 末尾持续追加修复覆盖；修改对应职责文件。保留 `prefers-reduced-motion` 支持。

## 本轮表现

- 正文 15px、行高 1.8，阅读列最多 960px；正文与输入框共用 `--card-content-gutter`，桌面最小左右留白 20px、手机 12px；统一标题、表格、引用、代码的层级。
- 会话栏合并模型信息；已锁定模型显示为只读信息，原锁定规则不变。
- 左侧导航支持收起；窄屏提供可展开导航。桌面助手并排，宽度小于 1280px 时使用抽屉；700px 以下优化控件与导航布局。
- 前景卡片水平、祖先卡片逆时针旋转。背景不再渲染整段历史原文；仅显示装饰性内容轮廓，并从辅助阅读树隐藏。
- 选词后的引用、探索使用独立图标；发送、附件、关闭、新建、历史和设置入口采用统一 SVG 表达。
- 新按钮继续复用原业务处理函数；额外保留输入法组合状态检查，避免中文候选确认的 Enter 被当成发送。

## 验证

- 现有 10 个测试文件、84 项自动测试通过。
- 客户端生产构建、服务端 TypeScript 检查通过；构建仍有原有的大包体积提示。
- 浏览器检查 1440px 桌面、1280px 默认窗口、390px 窄屏，检查亮色与深色主题。
- 已实际操作：导航展开/收起和会话选择、打开与关闭助手、保留主卡片草稿、助手流式输出与重开恢复、选词引用/移除引用、选词新建探索分支并流式回答、设置页展示。
- 未调用真实 Provider；未修改用户真实会话数据。上述验证覆盖本轮改动的主要交互，不意味着所有设备和所有输入场景都已穷尽验证。

隔离预览：先 `npm run build`，再 `npx tsx scripts/preview-ui.ts`。访问 `http://127.0.0.1:8796/`；`?preview-theme=dark` 仅在测试服务器上强制暗色。临时数据库路径在导入应用前及填充样例前均有断言校验。

## 本轮未改动

保留原有自动滚动、消息发送/停止和分支数据逻辑。复杂设置操作菜单重组、完整弹窗焦点管理、长会话虚拟列表可单独安排，避免与此次视觉调整混合。

## 跨分支术语引用反馈（2026-09-10）

- 普通点击已探索术语，来源与目标不在同一祖先路径上时，在树上显示一条临时虚线；由来源向目标绘出，约 2.8 秒后淡出并清理。
- 普通树导航、面包屑导航、同卡片/祖先/后代跳转不触发；连续术语跳转只保留最新一次提示，不新增真实树边或模型请求。
- 虚线跟随画布平移、缩放，hover 不重播；节点在画布外时在对应边缘提示，不强制改变缩放。减少动态效果设置下改为静态短暂提示。
- 隔离验证：`KK_PREVIEW_REFERENCE=1 npx tsx scripts/preview-ui.ts`，从“身份与记忆”正文点击“城市空间”可观察效果。分支判断、几何和术语接口回归共 16 项测试通过；浏览器验证虚线、自动清理、反向与连续跳转、普通导航取消及同分支不触发。未调用真实模型。
