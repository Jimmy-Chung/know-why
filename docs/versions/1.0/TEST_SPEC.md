## 1. 测试范围与环境

1.0 是个人本机使用版，通过浏览器访问本地服务，**不包含登录、注册及多用户模块**。登录、退出和用户间权限隔离属于 [1.1](../1.1/PRODUCT_SPEC.md)，不作为 1.0 的交付条件。

目标环境为当前 macOS 与桌面浏览器。正式测试时记录系统、浏览器、应用构建版本、模型 ID、接口类型、搜索服务和测试日期，不记录明文密钥。浏览器缩放、窗口变窄和键盘操作列入交互检查。

分三类记录结果：

- 原型检查：验证界面与操作表达，示例回答不能验证模型、搜索或存储。
- 模拟集成：验证参数映射、状态、失败路径、快照和数据边界。
- 真实联调：使用本机配置的真实模型及搜索服务，验证实际返回、来源及用量。

这三类结果分别记录，不能用原型或模拟通过代替真实联调。

## 2. 测试数据与前置条件

- 配置 OpenAI、DeepSeek 两个 Provider，指定其中一个为默认；另准备一个没有原生搜索能力的兼容模型。
- 独立搜索服务配置有效凭据，另准备可控的鉴权失败、不可达和空结果场景。
- 会话甲讨论影视叙事，主卡片包含“赛博朋克是一类科幻表达”和《阿基拉》；创建《阿基拉》与另一个概念的兄弟分支，再创建孙分支。
- 会话乙写入只存在于该会话的测试标记，用于验证知识助手不会跨会话召回。
- 准备带重复术语、Markdown 强调、跨行文本的回答，以及可以触发上下文摘要的长记录。
- 所有正式应用用例从明确的数据库初始状态执行；删除和恢复使用可丢弃的测试数据。

## 3. 用例与预期结果

每个用例初始状态均为 **未执行**。A 编号对应产品说明书中的验收条目。

| 用例 | 关联 | 操作步骤 | 预期结果 |

| T02 默认模型与锁定 | A01 | 设置默认 Provider；新建会话并切换模型；发送首条消息；进入子卡片和知识助手；修改全局默认项后再建会话。 | 首条消息前可切换；开始聊天后全会话绑定不变；新默认值仅影响以后创建的会话。 |
| T03 锁定边界 | A01 | 分别发送空消息、本地校验失败消息、通过本地校验但远端失败的消息；另建会话先向知识助手发消息。 | 前两者不锁定；进入处理队列后即使远端失败也锁定；知识助手首条消息同样触发锁定。 |

| T08 卡片堆叠 | A06 | 创建多层分支；切换父、子及兄弟卡片；输入、选词、调整窗口宽度。 | 当前卡片始终水平清晰；背景逆时针旋转并模糊；文字可读，输入与选词未被背景遮挡。 |

| T11 真实 Provider | A08 | 各使用 OpenAI、DeepSeek 发送一条消息并持续追问；再测试无效凭据和不存在的模型。 | 获得真实响应与流式状态；错误原因可辨；不会用演示答案冒充调用成功。 |

| T13 独立搜索 | A14 | 使用无原生搜索能力的兼容模型，配置独立搜索，强制搜索并回答。 | 本地服务实际调用独立搜索；模型绑定不变；回答引用映射到真实资料；资料摘要与实际抓取正文可区分。 |
| T14 搜索异常 | A10 | 搜索凭据无效、网络超时、空结果、来源读取失败；在强制模式尝试继续。 | 明确区分错误和无结果，不显示虚假的已核实状态；失败可重试或主动关闭联网；不静默切换未配置服务。 |
