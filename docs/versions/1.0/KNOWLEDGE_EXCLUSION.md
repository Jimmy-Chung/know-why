# 1.0 回答的助手知识管理

已完成的卡片回答默认纳入助手知识。回答下方提供“从助手知识中排除”和“重新纳入助手知识”；排除状态持久保存，不删除原文，不改变卡片聊天上下文。

修改从下一次助手提问生效，已经开始生成的回答不撤回。排除时整条回答的检索片段和向量被清除，缓存版本失效。恢复时重新建立片段，向量沿用现有异步补齐流程，无需再次调用聊天模型。

为避免旧助手回答间接重复被排除的信息，每次实际修改知识范围后，该会话之前的助手问答停止参与后续上下文，历史仍可查看；新问答正常积累上下文。恢复知识不会重新启用旧助手上下文。用户主动引用旧文字或其他回答重复相同内容，不属于本功能的自动排除范围。

数据库迁移：0012_knowledge_exclusion.sql，服务启动时执行。

验证：构建通过；RAG 和数据库共 32 项测试通过，包括多片段排除、缓存与语义检索失效、恢复、查询期间排除以及助手历史过滤。隔离浏览器验证排除、刷新持久化和重新纳入操作。
